## Rules

- Do not copy an asset into production without recording its source.
- Interface screenshots may contain project imagery; use them only as contextual evidence until standalone reuse rights are confirmed.
- Optimised production derivatives must not overwrite source files.
- Store source and production derivatives separately.
- Record attribution requirements where applicable.
